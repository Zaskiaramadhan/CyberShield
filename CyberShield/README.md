# CyberShield
CyberShield adalah aplikasi web edukasi yang membantu pengguna meningkatkan
kesadaran dan keamanan dalam menggunakan akun digital.

## Fitur
- 🔗 Link & Authenticity Checklist (membantu memeriksa keamanan link).
- 🎣 Social Engineering Explainer  (edukasi tentang phishing, baiting,
  smishing, dan identity theft).
- 🔐 Password Manager (edukasi mengenai penggunaan password yang aman
  dan tidak menggunakan kata sandi yang sama di berbagai akun).

## Tujuan
Membantu pengguna mengenali ancaman keamanan digital seperti phishing,
link berbahaya, dan pencurian identitas serta meningkatkan kebiasaan
penggunaan akun yang lebih aman.

## Teknologi
- HTML
- CSS
